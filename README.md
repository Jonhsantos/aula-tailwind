# Exercícios de Tailwind CSS e React

Atividade da disciplina de Single Page Application, organizada em duas partes:
laboratórios no Tailwind Play e componentes estáticos em React + Tailwind CSS.

## Executar o exemplo React

Requer Node.js e npm. Na raiz do projeto:

```bash
npm install
npm run dev
```

Abra o endereço exibido pelo Vite. `npm run build` gera a versão de produção.
Os componentes estão em `src/components/` e são reutilizados na galeria. As
ações são demonstrações visuais, sem autenticação, compra ou dados reais.
